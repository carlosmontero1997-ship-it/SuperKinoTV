**Add backtesting engine functions** after the `verify_winning_numbers()` function (after line 476), before `render_sidebar()`:

1. **`compute_hypergeometric_baseline(ticket_numbers: Tuple[int, ...], drawn_numbers: Tuple[int, ...], pool_size: int = 80, draw_size: int = 20) -> float`**
   - Computes exact hypergeometric probability of getting exactly k successes when drawing `draw_size` from `pool_size`, given the player's numbers
   - Uses `sp_stats.hypergeom.pmf(k, pool_size, draw_size, len(ticket_numbers))` where k = number of ticket numbers that appear in drawn_numbers
   - Returns the probability (float) — this is the expected hit probability for a random player

2. **`compute_hypergeometric_expected_hits(ticket_numbers: Tuple[int, ...], n_test_draws: int, pool_size: int = 80, draw_size: int = 20) -> List[float]`**
   - For each possible k (0 to len(ticket_numbers)), compute the hypergeometric PMF
   - Returns a list of expected hit counts per test period: the sum of P(k) * k for k=0..10
   - This gives the expected aciertos per draw for a random player

3. **`run_monte_carlo_baseline(ticket_numbers: Tuple[int, ...], n_test_draws: int, n_simulations: int = 1000, pool_size: int = 80, draw_size: int = 20) -> Tuple[List[float], float]`**
   - Run `n_simulations` random simulations, each simulating `n_test_draws` random draws
   - Each random draw: sample `draw_size` numbers from 1..pool_size uniformly
   - Track aciertos per draw across all simulations
   - Returns `(avg_aciertos_per_draw_list, overall_avg_hit_rate)` where `avg_aciertos_per_draw_list[i]` is the average aciertos at test period i across all simulations, and `overall_avg_hit_rate` is the total hits / total draws across all simulations

4. **`apply_temperature_to_selection(ranked_numbers: List[Tuple[int, float, int]], temperature: float, pool_size: int, band_dist: Optional[Tuple[int, int, int]]) -> List[int]`**
   - Temperature-controlled pool generation: instead of always taking the top N from frequency ranking, use temperature to weight selection probability
   - Convert frequency scores to selection probabilities using softmax with temperature: `prob[i] = exp(score[i] / T) / sum(exp(score[j] / T))`
   - Use `numpy.random.choice` with these probabilities to select `pool_size` numbers (without replacement)
   - If `band_dist` is provided, apply band constraints (select proportionally from each band using temperature-weighted probabilities within each band)
   - This function replaces `generate_dynamic_pool()` when temperature < 2.0 (at T=2.0, distribution approaches uniform = random)
   - Returns sorted list of selected numbers

5. **`walk_forward_backtest(draws: List[Draw], config: Dict, temperature: float = 1.0, n_tickets: int = 18, ticket_size: int = 10, mc_simulations: int = 1000) -> Dict`**
   - Main walk-forward engine. Per CONTEXT.md decisions:
     - Training window = `config["window"]` (default 80, range 20-100)
     - Test period = always 1 draw
     - Step size = always 1
     - Runs until no more test draws available
   - Algorithm:
     ```
     results = []
     for start in range(0, len(draws) - training_window):
         train_draws = draws[start : start + training_window]
         test_draw = draws[start + training_window]
         
         # Generate pool from training data (using temperature if < 2.0)
         if temperature < 2.0:
             pool = apply_temperature_to_selection(
                 compute_frequency_ranking(train_draws, training_window),
                 temperature, config["pool_size"], config.get("band_dist"))
         else:
             pool, _ = generate_dynamic_pool(
                 train_draws, training_window, config["pool_size"], config.get("band_dist"))
         
         # Generate tickets via wheeling
         tickets, errors = wheeling_reduction(pool, n_tickets, ticket_size)
         
         # Count aciertos for each ticket
         test_numbers = set(test_draw.numbers)
         best_aciertos = max(
             len(set(t) & test_numbers) for t in tickets
         ) if tickets else 0
         
         # Hypergeometric baseline for this test period
         # Use first ticket's numbers as representative
         hyper_expected = compute_hypergeometric_expected_hits(
             tickets[0], 1)[0] if tickets else 0
         
         # Monte Carlo baseline for remaining test periods
         remaining_test_draws = len(draws) - (start + training_window + 1)
         mc_avg, mc_overall = run_monte_carlo_baseline(
             tickets[0], max(1, remaining_test_draws), mc_simulations) if tickets else ([], 0)
         
         results.append({
             "test_draw_idx": start + training_window,
             "test_draw": test_draw,
             "train_window": (start, start + training_window),
             "best_aciertos": best_aciertos,
             "hyper_expected": hyper_expected,
             "mc_avg_aciertos": mc_avg[0] if mc_avg else 0,
             "tickets": tickets,
         })
     ```
   - Returns dict:
     ```python
     {
         "results": results,  # List of per-period results

         "cumulative_hyper": List[float],  # Running total of hypergeometric expected

         "n_test_periods": int,
         "total_cost": float,  # n_tickets * n_test_periods * 75 (RD$ per volante)

     }
     ```

## Spacing Scale

Streamlit controls spacing internally. Documenting the effective scale via Streamlit layout containers:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Inline icon gaps, badge padding |
| sm | 8px | Compact widget spacing, sidebar control gaps |
| md | 16px | Default element spacing, paragraph margins |
| lg | 24px | Section padding (st.container border padding) |
| xl | 32px | Major section breaks (st.divider margins) |
| 2xl | 48px | Tab-to-content gap |
| 3xl | 64px | Page-level spacing (st.header top margin) |

Exceptions: Sidebar uses Streamlit's default sidebar width (~330px). No custom touch targets needed (desktop-only tool).

## Typography

Streamlit uses system fonts. Documenting the effective sizes via `st.header`, `st.subheader`, `st.markdown`, `st.caption`:

| Role | Size | Weight | Line Height | Streamlit Element |
|------|------|--------|-------------|-------------------|
| Body | 16px | 400 (regular) | 1.5 | `st.markdown()`, `st.write()` |
| Label | 14px | 400 (regular) | 1.4 | `st.caption()`, widget labels |
| Heading | 24px | 600 (semibold) | 1.2 | `st.header()` |
| Subheading | 18px | 600 (semibold) | 1.3 | `st.subheader()` |

**Note:** Streamlit renders `st.title()` at ~32px but is only used for the page title. `st.header()` at ~24px is the max recurring heading size.

## Interaction Contracts

### Data Ingestion Flow

1. **Dual input** — file uploader + text area side-by-side (equal width `st.columns([1,1])`)
2. **Auto-process** — ingestion triggers on any input change (no explicit "process" button needed)
3. **Strict validation (D-01, D-02)** — ALL lines must pass; any failure blocks entire load
4. **Error display (D-03, D-04, D-05, D-06, D-07)** — errors in `st.expander` below input, numbered "Linea N: motivo"
5. **Success display** — `st.success` banner with count

### Band Distribution Flow

1. **Preset selector** — `st.sidebar.selectbox` with options: "Equilibrada Dinamica", "4-3-3", "3-4-3", "3-3-4", "Personalizada"
2. **Personalizada mode** — 3 `st.number_input` in a row (`st.columns(3)`), auto-recalculate on pool size change (D-08)
3. **Sum validation (D-09)** — if Baja+Media+Alta != pool_size, show warning: "La suma (N) no coincide con el pool (M)"
4. **Equilibrada Dinamica** — calculated proportionally, show `st.info` confirmation

### Data Persistence (D-12)

1. **Session state** — `st.session_state.draws` persists across all tabs
2. **Replace confirmation (D-13)** — if `st.file_uploader` gets new file while data exists, show `st.warning` + confirmation
3. **Dual source detection (D-14)** — if both file and text area have content, show `st.radio` selector

### Sidebar Control Behavior

1. **Window slider** — max auto-adjusts to `min(100, total_draws)`, min=10
2. **Pool size** — independent, 15-30 range
3. **Ticket count** — independent, 6-30 range
4. **All controls** — update immediately on change (Streamlit rerun behavior)

## Streamlit-Specific Patterns

### Icons
- Replace emoji icons with Material Symbols: `:material/icon_name:`
- File upload: `:material/upload:`
- Settings: `:material/tune:` (sidebar header)
- Tables: `:material/table_chart:`
- Analytics: `:material/query_stats:`
- Tickets: `:material/style:`

### Session State Keys
| Key | Type | Purpose |
|-----|------|---------|
| `draws` | `List[Draw]` | Parsed draw data, persists across tabs |
| `errors` | `List[Tuple[int, str]]` | Parse errors for display |
| `config` | `Dict` | Sidebar configuration dict |

### Widget Labels
- Use `label_visibility="hidden"` where label is obvious from context
- Use sentence casing (not title casing) per Streamlit skill best practices
- All labels in Spanish

### Caching
- No expensive computation in Phase 1 — ingestion is fast
- `@st.cache_data` not needed for parse_line/ingest_lines (called on every rerun with user input)

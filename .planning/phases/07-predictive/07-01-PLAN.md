2. **`compute_temporal_patterns(draws: List[Draw], window: int) -> Dict`**
   - Analyze day-of-week patterns: for each day (0=Monday..6=Sunday), count number frequencies
   - Analyze band distribution trends: for each band, compute rolling average frequency over last 10, 20, 30 draws
   - Detect cyclical behavior: if a band's frequency oscillates (e.g., alternating high/low), flag it
   - Return dict:
     ```python
     {
         "day_of_week_freq": Dict[int, Dict[int, float]],  # {day: {number: normalized_freq}}
         "band_trends": Dict[str, List[float]],  # {band_name: [rolling_avg_freq at 10,20,30 draws]}

     }
     ```

3. **`compute_predictive_scores(draws: List[Draw], window: int, temperature: float = 1.0) -> Dict`**
   - Main scoring engine. Combines ALL factors from CONTEXT.md:
     a. **Frequency score** (from `compute_frequency_ranking`): normalized 0-1
     b. **Gap score**: numbers with moderate gaps (not too cold, not too hot) score higher. Gap score = 1 - |gap - optimal_gap| / window, where optimal_gap = window / 20 (average expected gap for 20 numbers in 80)
     c. **Co-occurrence score**: from `compute_cooccurrence_matrix`, average co-occurrence with top-20 numbers
     d. **Temperature-weighted recency**: use temperature to weight recent draws more heavily. For each number, compute recency-weighted frequency = sum(exp(-decay * (window - last_seen_idx)) for each appearance), where decay = 1/T
     e. **Temporal pattern score**: from `compute_temporal_patterns`, boost numbers that appear frequently on the current day-of-week
     f. **Band trend score**: boost numbers in bands that are trending up (recent_band_shift > 0)
   - Combined score: weighted sum of all factors
     ```python
     weights = {
         "frequency": 0.25,
         "gap": 0.15,
         "cooccurrence": 0.20,
         "recency": 0.15,
         "temporal": 0.10,
         "band_trend": 0.15,
     }
     ```
   - Final score normalized to 0-100 (confidence score)
   - Return dict:
     ```python
     {
         "number_scores": List[Dict],  # [{"number": int, "score": float (0-100), "factors": {"frequency": float, "gap": float, ...}}, ...]
         "temporal_patterns": Dict,  # from compute_temporal_patterns
         "cooccurrence_top_pairs": List[Tuple[int, int, float]],  # top 20 co-occurring pairs
     }
     ```

4. **`suggest_band_distribution(draws: List[Draw], window: int, predictive_scores: Dict) -> Dict`**
   - Analyze band distribution trends and suggest optimal distribution
   - Logic:
     a. Compute historical band frequency over last window draws
     b. Identify which bands are "hot" (frequency > expected) and "cold" (frequency < expected)
     c. If a band is trending up (recent_band_shift > 0), suggest higher allocation
     d. If a band is cyclical, check current phase and adjust
     e. Suggest a distribution (e.g., 4-3-3, 3-4-3, etc.) with confidence level
   - Return dict:
     ```python
     {
         "suggested_distribution": Tuple[int, int, int],  # (low, mid, high) counts for 10-number ticket
         "confidence": float,  # 0-100
         "reasoning": str,  # "Baja trending up (+12%), Media stable, Alta trending down (-8%)"
         "alternative_distributions": List[Dict],  # [{"dist": (4,3,3), "confidence": 85, "reason": "..."}]
         "band_analysis": Dict[str, Dict],  # per-band: {"frequency": float, "trend": str, "hot/cold": str}
     }
     ```

5. **`recommend_tickets(draws: List[Draw], predictive_scores: Dict, band_suggestion: Dict, config: Dict) -> Dict`**

     ```python
         "pool_used": List[int],  # the predictive pool used
         "total_score": float,  # average score across recommended tickets
     }
     ```

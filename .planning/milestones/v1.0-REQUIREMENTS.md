## Key Decisions Archive

### Data Format
- **Format:** DD/MM/YYYY,N1,N2,...,N20 per line
- **Ascending sort:** All 20 numbers sorted after parsing
- **Validation:** Format pattern, range 1-80, exactly 20 numbers/line

### Number Generation
- **Temperature:** T ∈ [0.05, 2.0] softmax distribution
- **Pool dynamic:** Ranked by des-duplicated frequency + co-occurrence
- **Wheeling:** 3 juegas per volante, RD$75 cost, ascending order, 0 duplicates

### UI Architecture
- **5-page Streamlit app:** Home, Historial, Analisis, Combinaciones, Simulador
- **Sidebar controls:** ventana móvil, pool size, boletos count, franja distribution
- **Determinism constraints:** 0 numbers outside pool, strict ascending order, 0 duplicates

### Quality Gates
- **Honest statistics:** Theoretical floors always visible
- **Random baseline:** Mandatory comparison in all statistical output
- **Code quality:** black formatting, type hints, NumPy docstrings

# Milestone v1.1: Keno Analysis & Wheeling

**Status:** ✅ SHIPPED 2026-08-26
**Phases:** 1-3
**Total Plans:** 5

## Overview

Consolidated Keno 20/80 analysis and ticket generation into a single Streamlit app with strict data validation, deterministic wheeling algorithm, and winning number verification.

## Phases

### Phase 1: Data Ingestion & Controls

**Goal:** User can upload/paste historical Keno data and configure all analysis parameters via sidebar controls.
**Depends on:** Phase 1 (v1.0 foundation)
**Plans:** 2 plans

Plans:
- [x] 01-01-PLAN.md — Strict data ingestion with dual source detection, replace confirmation, session state persistence
- [x] 01-02-PLAN.md — Sidebar controls with forced Personalizada band distribution, auto-recalc, sum validation, colored metrics

**Details:**
- All-or-nothing validation: any error blocks all data loading
- 1-indexed line numbers in error messages with raw line content display
- Session state persistence of draws across all Streamlit tabs
- Dual source detection (file + text area) with user choice
- Replace confirmation when overwriting existing data
- Material Symbols icons throughout UI

### Phase 2: Analysis Matrices & Pool Generation

**Goal:** Display intermediate frequency matrices and generate ranked dynamic pool from statistical analysis.
**Depends on:** Phase 1
**Plans:** 2 plans

Plans:
- [x] 02-01-PLAN.md — Gap analysis, conditional formatting, frequency totals
- [x] 02-02-PLAN.md — Full 80-number ranking, band colors, gap context

**Details:**
- Gap analysis function computing draws since last appearance for all 80 numbers
- Conditional formatting: intermediate matrix cells highlighted blue/gray
- Band color coding: Baja=blue, Media=yellow, Alta=red
- Full 80-number frequency ranking with pool membership indicator
- Gap analysis integrated into pool display

### Phase 3: Wheeling, Volantes & Ticket Verification

**Goal:** Generate deterministically reduced ticket sets, organize into physical volantes, and verify against winning numbers.
**Depends on:** Phase 2
**Plans:** 1 plan

Plans:
- [x] 03-01-PLAN.md — Winning number verification with aciertos tracking

**Details:**
- Deterministic wheeling reduction algorithm (greedy pair-coverage)
- Fixed critical bug: no longer pads with non-pool numbers
- Strict blindaje enforcement: 0 out-of-pool numbers, ascending sort, 0 duplicates
- Tickets grouped into volantes of 3 plays each
- Download button exports all generated tickets as .txt
- verify_winning_numbers() function with per-ticket aciertos tracking
- Summary metrics: best aciertos, total matches, distribution

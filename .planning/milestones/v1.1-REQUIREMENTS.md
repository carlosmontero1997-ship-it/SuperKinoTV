# Requirements Archive: SuperKinoTV v1.1

**Defined:** 2026-08-26
**Shipped:** 2026-08-26
**Core Value:** Deterministic combinatorial analysis and wheeling-based ticket generation from historical Keno 20/80 data

## Completed v1 Requirements

### Data Ingestion
- [x] DATA-01: User can upload .txt or .csv file with historical draw data — Phase 1 ✅
- [x] DATA-02: User can paste draw data directly into a text area — Phase 1 ✅
- [x] DATA-03: System parses DD/MM/YYYY,N1,...,N20 format per line — Phase 1 ✅
- [x] DATA-04: System sorts 20 numbers per draw ascending (low to high) — Phase 1 ✅
- [x] DATA-05: System validates numbers in range 1-80 and exactly 20 unique per draw — Phase 1 ✅

### Controls
- [x] CTRL-01: Sidebar slider for sliding window (max 100 retroactive draws) — Phase 1 ✅
- [x] CTRL-02: Sidebar slider for dynamic pool size (15-30, default 20) — Phase 1 ✅
- [x] CTRL-03: Sidebar slider for ticket quantity (6-30, default 18) — Phase 1 ✅
- [x] CTRL-04: Sidebar selector for band distribution (Low/Mid/High preset or custom) — Phase 1 ✅ (changed to forced Personalizada)

### Matrices Tab
- [x] MATX-01: Display 100×20 intermediate matrix (sorted draws × positions) — Phase 2 ✅
- [x] MATX-02: Display 10×10 positional frequency matrix grouped by adjacent lane pairs — Phase 2 ✅

### Pool Tab
- [x] POOL-01: Generate dynamic pool of N numbers from deduplicated frequency + co-occurrence ranking — Phase 2 ✅
- [x] POOL-02: Display pool with band metrics (count in Low 01-26, Mid 27-54, High 55-80) — Phase 2 ✅

### Tickets Tab
- [x] TICK-01: Execute deterministic wheeling reduction algorithm on dynamic pool — Phase 3 ✅
- [x] TICK-02: Group tickets into physical volantes (3 tickets per volante) — Phase 3 ✅
- [x] TICK-03: Display cost indicator (RD$75 per volante) — Phase 3 ✅
- [x] TICK-04: Enforce strict blindaje: 0 numbers outside pool, ascending sort, 0 duplicates — Phase 3 ✅
- [x] TICK-05: Provide .txt download button for generated tickets — Phase 3 ✅
- [x] TICK-06: Allow user to input winning numbers and verify aciertos (matches) per ticket — Phase 3 ✅
